# 20 — Future Feature Backlog

This is intentionally not a commitment that every item will be implemented.

## Editing

- liquify
- perspective warp
- puppet warp
- content-aware operations
- advanced healing
- advanced cloning
- dodge/burn
- smudge
- channel mixer
- curves
- levels
- color balance
- selective color
- HDR-oriented workflows

## Design

- smart guides
- component-like reusable elements
- templates
- artboards
- multiple canvases
- symbols
- reusable styles

## Automation

- action recording
- batch processing
- macros
- scripting API

## AI — optional future

AI capabilities could eventually include:

- background removal
- object selection
- generative fill
- image expansion
- object removal
- semantic search

Any AI service that sends user data externally requires an explicit architecture and privacy decision.

## Collaboration — optional future

- multiplayer editing
- comments
- review mode
- sharing
- cloud projects

These features are deliberately outside the initial local-only architecture.
