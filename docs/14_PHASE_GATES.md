# 14 — Implementation Phases & Gates

## Gate 0 — Repository Foundation

Deliver:

- Next.js application
- TypeScript
- ESLint
- formatting
- testing
- CI
- basic routing
- error boundaries
- logging strategy

Do NOT implement advanced editing.

### Gate 0 acceptance

A clean repository builds, tests and deploys to Vercel.

---

## Gate 1 — Editor Shell

Deliver:

- editor route
- toolbar
- menus
- canvas viewport
- right-side panel
- document tabs
- zoom/pan

### Gate 1 acceptance

A user can navigate the editor and manipulate the viewport.

---

## Gate 2 — Document Engine

Deliver:

- document model
- layer model
- command system
- history
- serialization
- IndexedDB persistence

### Gate 2 acceptance

A document can be created, modified, saved locally and restored.

---

## Gate 3 — Core Editing

Deliver:

- move
- crop
- transform
- brush
- eraser
- shapes
- text
- basic export

### Gate 3 acceptance

MYLPER becomes a useful basic image editor.

---

## Gate 4 — Professional Layer Workflow

Deliver:

- groups
- masks
- blend modes
- opacity
- adjustment layers
- layer effects

### Gate 4 acceptance

A multi-layer composition can be built non-destructively.

---

## Gate 5 — Selection & Advanced Tools

Deliver selection subsystem and advanced brushes/tools.

### Gate 5 acceptance

Professional compositing workflows are possible.

---

## Gate 6 — Formats

Deliver robust:

- PNG
- JPEG
- WebP
- SVG
- PDF where feasible
- PSD foundation

### Gate 6 acceptance

Users can move projects between MYLPER and common creative tools.

---

## Gate 7 — Performance

Profile large documents.

Deliver:

- workers
- caching
- optimized rendering
- memory protections
- progressive rendering
- large-document UX

### Gate 7 acceptance

Large realistic documents remain usable without freezing the browser.

---

## Gate 8 — SEO/AEO & Monetization

Deliver:

- marketing pages
- documentation
- blog
- structured data
- sitemap
- robots
- Google Ads integration
- custom sponsorship system
- consent system

### Gate 8 acceptance

Public website is indexable, fast and monetizable without compromising privacy.

---

## Gate 9 — Professional Parity

Continue feature development toward:

- paths
- advanced color
- filters
- smart objects
- advanced PSD
- professional shortcuts
- guides
- snapping
- automation

This phase is intentionally open-ended.

---

## Gate 10 — Optional Cloud Architecture

Only begin after explicit product-owner approval.

Potential:

- accounts
- cloud storage
- collaboration
- sync
- AI services

This must not compromise the local-first architecture.
